## 8. Leakage-Controlled Pipeline — AUTHORITATIVE

The actual final methodology is a training-only/fold-specific pipeline.

Pipeline order:

1. `InfinityMaxImputer()`
   - Fits per-column maximum finite values using training data only.
   - Replaces Infinity values using those learned training values.

2. `CorrelationFilter(0.95)`
   - Fits on training data only.
   - Removes features involved in pairwise absolute correlation above 0.95.

3. `RandomUnderSampler('majority', random_state=42)`
   - Training only.
   - Dynamically undersamples the majority attack class to match the minority benign count.

4. Final model only:
   `SelectKBest(mutual_info_classif, k=K)`
   - Fits on training data only.
   - For cross-validation, selection occurs independently inside each fold.

5. Classifier:
   - Decision Tree or Random Forest.

The test/holdout set must never influence:
- imputation values
- correlation filtering
- undersampling
- MI feature selection
- model fitting

Use the term **leakage-controlled**, not "perfectly leakage-free."

IMPORTANT:
Do NOT describe the balancing as a hard-coded 1,302/1,302 target. The 1,302 value is the benign count in the complete training partition. The implementation uses `RandomUnderSampler(strategy='majority')`, so the majority class is dynamically reduced to match the minority class in each fit.
